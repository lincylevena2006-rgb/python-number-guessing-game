# 🎯 Number Guessing Game

A simple command-line game built using Python where the player tries to guess a randomly generated number between 1 and 100.

## ✨ Features

* Random number generation
* Number range from 1 to 100
* Hints for each guess
* Attempt counter
* Invalid input handling

## 🛠️ Technologies Used

* Python 3
* Random module

## 📂 Project Structure

```text
NumberGuessingGame/
├── guessing_game.py
└── README.md
```

## ▶️ How to Run

Open the terminal in the project folder and run:

```bash
python guessing_game.py
```
